# ─────────────────────────────────────────
# PHILOSOPHY
#
# The baseline follows three principles:
#
# 1. READING IS FREE, TAKING IS NOT
#    Agents can read and summarise. They cannot train on,
#    monetise, or build derivatives from content by default.
#
# 2. CREDIT THE CREATOR
#    Attribution is always required. Link-backs are preferred.
#    If you use someone's work, say so.
#
# 3. SILENCE MEANS NO
#    If a site owner hasn't said yes, assume no.
#    If the ask endpoint doesn't exist, assume deny.
#    If in doubt, don't.
#
# These defaults protect creators while keeping the web useful.
# They can be loosened by any site owner at any time.
# They should never need to be tightened.
